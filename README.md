# 📚 StudyPDF AI

StudyPDF AI is an intelligent academic assistant that helps students interact with their study materials using Generative AI. Users can upload one or more PDF documents, and the application extracts the content, analyzes it, and provides AI-powered assistance for learning and exam preparation.

The system allows students to ask questions directly from the uploaded PDF, generate university-style 2-mark and 16-mark questions with answers, summarize lengthy chapters, extract specific topics, and identify important examination questions. All responses are generated using Google Gemini AI based on the uploaded document.

## ✨ Features

* 📄 Upload and analyze PDF documents
* 🤖 AI-powered question answering
* 📝 Generate 2-mark questions with answers
* 📖 Generate 16-mark questions with detailed answers
* 📋 Create chapter summaries
* 🔍 Extract specific topics from PDFs
* 🎯 Generate important exam questions
* 📊 Display document statistics
* 🎨 Modern and responsive user interface

## 🛠️ Technologies Used

* Python
* Flask

* CSS
* JavaScript

* Google Gemini AI
* Python Dotenv

## 🎯 Use Cases

* College students
* Competitive exam preparation
* Academic revision
* Digital note analysis
* Self-learning from PDF materials

StudyPDF AI simplifies learning by transforming static PDF documents into an interactive AI-powered study companion, helping students save time and prepare more effectively for examinations.
